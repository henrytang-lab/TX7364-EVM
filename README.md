The TX7364EVM is used for the evaluation of TX7364 
device under various drive strength, different voltage 
levels and different modes of the device. The EVM 
contains all necessary control signals and on-board 
power generation, which greatly reduces the need 
for external equipment. The evaluation system also 
includes GUI software for Microsoft® Windows® for 
easily programming various modes and patterns into 
the device.
Features
• Allows control of TX7364 device using simple GUI 
via USB
• B-mode or CW mode of transmit can be 
programmed
• Multiple pattern and Delay profiles can be stored, 
and user can switch between them easily in GUI
• Clock and Sync generator present on board
• Sync frequency can be changed using onboard 
potentiometer
• Option to give external sync
• Uses CMOS serial programming interface
• Error flag register to detect faulty conditions and 
automatic thermal shutdown
• Evaluate Transmit Performance with 100pF||1kΩ 
load
